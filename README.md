# resource_name

Simple reusable TypeScript boilerplate for FiveM resources.

## Usage

clone:

```bash
cd -LiteralPath 'D:\Fivem\txData\FiveMBasicServerCFXDefault_0CD946.base\resources\[dayone]'
git clone https://github.com/AlonyaJS/do_types.git resource_name
```

Run:

```bash
npm install
npm run build
```

During development, run:

```bash
npm run watch
```

Add this to your `server.cfg`:

```cfg
ensure resource_name
```

Edit files only in `src`, not `dist`. The `dist` folder is generated by the build scripts and is what `fxmanifest.lua` loads.

## Folder Structure

- `src/server` contains server-side TypeScript.
- `src/client` contains client-side TypeScript.
- `src/web` contains the NUI HTML, CSS, and browser TypeScript.
- `dist` contains compiled JavaScript and copied web files.
